# 小学英语点读 v1.7.1

本版提供完整本地离线英语跟读，并修复码云附件体积限制导致的安装包发布问题：模型与原生库采用无损压缩，保留全部模型权重、教材音频和图片。

## 功能更新

- **离线跟读完整流程**：长按句子或点击底栏麦克风，先听课本原音，再录音并查看逐词绿／黄／红反馈与 0–100 跟读匹配分；支持原音／自录音 AB 试听、“再读一次”和“完成”。
- **真实录音声浪**：声浪来自麦克风实时音量，支持手动停止、最长 15 秒保护，以及说话后 1.5 秒静音自动停止评分。录音权限只在点击录音时申请，拒绝可重试，永久拒绝可进入系统设置；后台中断取消录音，关闭抽屉释放麦克风和原生推理并清理临时 WAV。
- **安装包无损瘦身**：Android 原生库启用无损压缩，约 70.04 MiB 的完整英文模型使用 XZ 无损打包，缩减安装包以解决码云附件体积限制。没有缩减模型权重、删除课本音频或再次降低图片质量。
- **模型仍内置、仍离线**：首次跟读在独立 isolate 解压模型到应用私有目录，核对解压后原始文件 SHA-256；已准备的正确模型缓存可直接复用。录音、识别和评分均在本机进行，不上传录音，也不要求运行时联网下载模型。
- **首次准备与后续练习分开**：首次新增解压步骤，可能比此前直接复制模型耗时更长；准备和加载在独立线程完成，录音期间继续增量识别，停止录音后的评分耗时单独记录。
- **保留原有点读功能**：单句／整页／顺序连读、暂停／继续、六档语速、通知降音、阅读进度与应用内更新继续可用；原音和自录音使用同一播放器，避免叠播。

### 评分范围

当前 Sherpa 流式 Dart 接口不提供原生词级置信度。本版逐词反馈与分数来自识别文本匹配及完整度，不伪造模型概率，也不能判断音素、重音、语调或口音。儿童声音、教材人名及噪声可能导致识别错误，请结合 AB 试听练习。

## 验证

- 本次补丁测试：**367 项 Flutter 测试、151 项 Python 测试通过，`flutter analyze` 无问题**。
- 三个 ABI 正式 APK 构建完成，均小于 100 MiB；码云上传是否接受，仍以实际上传与匿名完整下载校验为准。
- v1.7.0 原跟读功能已通过 351 项 Flutter、148 项 Python 测试与静态分析；Android API 36 x86_64 断网模拟器已检查权限拒绝／重试授权、真实录音、15 秒保护、词级漏读反馈与 AB 试听。
- 原跟读实现的真实生产流式识别器，对 1.224 秒 `Good morning.` 音频实时推理，五次停止到评分为 29.065、17.477、22.745、22.711、19.952ms；首次模型加载约 2.95 秒。该首次加载结果不包含本补丁新增的 XZ 解压步骤，补丁首次准备耗时需单独验证。
- 本机未连接实体手机，不以模拟器结果承诺所有设备均在 300ms 内评分，也不承诺所有儿童声音或噪声环境的识别效果。
