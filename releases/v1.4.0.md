# 湘少英语三上点读 v1.4.0

本版汇总通知降音、六档倍速和应用内更新，并增加码云公开下载渠道。

## 功能更新

- **通知降音，连读继续**：系统通知或导航请求降音时，将播放音量临时降至 25%，结束后平滑恢复原音量；来电等需要暂停的中断、耳机拔出和后台切换仍暂停并保留高亮。
- **六档倍速自由选择**：支持 0.5x、0.8x、1.0x、1.2x、1.5x、2.0x。点按依次循环，长按打开直选列表，立即作用于当前及后续音频，关闭重启后自动恢复上次语速。
- **应用内检测和安装更新**：启动时自动检查码云新版本，书架也提供“检查更新”。确认后直接在应用内下载、显示进度，下载完成打开系统安装器；支持取消下载、取消安装后重试。
- **必要权限按安装流程申请**：首次安装更新时，提示允许本应用安装新版本；返回后继续安装。下载使用应用私有目录，不申请广泛存储权限。
- **保留学习体验**：通知降音期间手动点读仍保持低音量，通知结束才恢复；整气泡连读、跨页、单句热区、目录、译文、阅读进度和原教材音频继续保留。
- **新增码云同仓发布**：码云、GitHub、AtomGit 每个平台仅维护一个公开源码与 Release 仓库，安装包带版本号，并提供中文版本说明和 SHA-256 校验文件。
