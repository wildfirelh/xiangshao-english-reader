# 湘少英语三上点读 v1.2.0

本版更新全书英语音频，并改善人物声线、对话连读顺序和点读高亮。

## 功能更新

- **全书豆包 2.0 音频**：65 页教材的 1,185 条点读音频全部重新合成，安装后可离线播放。
- **固定角色声音**：女学生、男学生、女教师、男教师、Dino 和旁白分别使用固定音色。结合插图上下文核对 367 条人物标注；Dino 使用独立声线，合成语速为 1.06 倍，音调参数为 3。
- **更顺畅的对话连读**：优先按漫画场景数字排序；同一场景依次播放提问或发起对话、应答、致谢告别，并补充无编号插图和跨框气泡的场景归属。
- **荧光笔式点读高亮**：移除边框，使用 22% 不透明度的黄色底色和 4dp 圆角，让当前句子更清楚、教材文字更容易阅读。
- **更可靠的教材生成**：音频按文字、角色与合成参数缓存并校验内容，网络异常可重试；全部音频成功后才替换教材清单，失败后可继续利用已完成缓存。
- **完整的版本交付**：APK 文件名包含版本、构建号和架构，提供中文更新说明与 SHA-256 校验文件，并同步发布到 GitCode。
