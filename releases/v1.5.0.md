# 小学英语点读 v1.5.0

本版将应用升级为可扩展的多教材书架，并重构主界面与学习设置。

## 功能更新

- **全新多教材书架**：应用更名为“小学英语点读”，启动展示书架。根据教材清单展示高清封面、年级筛选和教材卡片；湘少版三年级上册可继续点读，三年级下册显示“准备中”。
- **悬浮胶囊导航**：“书本／我的”采用圆角深色玻璃悬浮底栏、青绿色选中态和平滑动画，切换后保留页面状态；适配小屏、大字体、深色模式与减少动画设置。
- **每本教材独立进度**：教材正文按需加载，独立维护封面、单元目录和阅读记录；书架显示页码与进度百分比，从阅读器返回后自动刷新，可直接继续上次位置。
- **真实学习统计**：“我的”展示累计点读天数与点读书籍数，只在音频实际开始时记录，同一天／同一本去重并保存到本地。本版开始累计，不推算旧版未记录的学习历史。
- **护眼提醒与语速偏好**：增加护眼提醒开关，开启后在阅读器前台每 20 分钟提示休息；“我的”可直接选择六档语速，与阅读器共用偏好，重启后恢复。
- **关于与更新入口**：“我的”提供实际安装版本、应用与教材版权说明及“检查更新”。保留单句点读、整气泡连读、手势打断、中文释义、跨页播放、通知降音和应用内下载更新能力。
