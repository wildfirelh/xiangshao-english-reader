# 湘少英语三上点读 v1.3.0

本版新增整气泡连读，并让手动点读随时接管播放。

## 功能更新

- **整气泡完整朗读**：整页连读按对话框／气泡播放，同一气泡的多个小句合并为一条完整段落音频；跨场景先遵循插图序号，同一场景按气泡阅读顺序播放，一页结束后继续下一页首个气泡。
- **手动点读立即打断**：点击页面上的任意句子热区或气泡，立即取消连读、待加载音频和待执行的跨页播放，底栏自动切回“单句点读”。所选小句播放完就停止，无需先手动切换模式。
- **单句热区独立保留**：小句仍有各自音频与精准热区；点击气泡中两行之间的空白时选择首个小句，句子热区优先，避免连读高亮扩大后影响点读位置。
- **高亮与释义跟随播放单位**：连读显示整气泡荧光高亮与整段释义，单句点读显示小句高亮；保留无描边的半透明底色、语速切换和重听。
- **双轨教材资源与缓存**：资源脚本根据 PDF 文本块、几何布局及校对数据生成气泡，避免跨场景、跨说话人合并。独立单句与整段音频均通过豆包 2.0 合成并按参数指纹缓存；一句的气泡直接复用单句 MP3。旧清单没有气泡结构时仍可兼容读取。
- **中断场景回归**：覆盖连读中、音频加载中、暂停后、缺失音频及自动翻页时的手动点读，保留目录导航、阅读进度、后台暂停和减少动态效果设置。

全书 65 页包含 1,185 个独立单句、1,137 个气泡，其中 43 个多句气泡。共 1,228 个 MP3，包含 1,185 个单句文件与 43 个多句气泡文件；整段音频新增 42 组合成配置，另 1 组复用既有缓存。全书音频均通过缓存 SHA-256 检查，译文无缺失；原单句文字、译文、热区与音频路径保持稳定。
