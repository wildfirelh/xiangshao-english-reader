# 小学英语点读 v1.6.0

本版增加三种播放模式与暂停／继续，点读起点、连读范围和手动翻页反馈更加清晰。

## 功能更新

- **三种播放模式**：单句点读独立朗读选中的小句，读完即停；整页连读从当前页首个气泡开始，使用完整气泡音频并高亮整个气泡，在当前页末尾停止。
- **从指定小句顺序连读**：未播放时选择顺序模式会显示选点待命提示，点击任意文本从精确小句开始，按教材气泡及其子句的原文次序继续，自动跨页读至全书末尾；再次点击文本可以立即更换起点。点击气泡内空白则从该气泡首句开始。
- **暂停后继续原位置**：连读提供显著的暂停／继续按钮，暂停保留当前高亮与音频位置，继续时从同一位置恢复。音频加载或跨页途中暂停也会停止后续自动播放，等待手动继续。
- **拖动即停止**：手指开始拖动页面时立即停止旧连读队列、清除高亮，取消未完成的音频加载和自动翻页，底栏同步恢复停止状态；上一页、下一页与目录跳转同样立即停止。整页连读时手动点读切回单句模式，顺序连读时手动点读更换起点。
- **模式与六档语速直接选择**：点按模式或倍速按钮即可打开底部单选列表，显示每项用途和当前勾选。支持 `0.5x / 0.8x / 1.0x / 1.2x / 1.5x / 2.0x`，选择立即生效并保存语速偏好；适配小屏、大字体、深色模式与系统减少动画设置。
- **通知降音更稳定**：修复系统降音期间切换播放模式或音频自然结束后提前恢复音量的问题，后续音频仍保持降音，收到系统降音结束事件后平滑恢复。需要暂停的系统中断、耳机拔出和应用后台继续保留高亮，等待手动恢复。
