# 小学英语点读 v1.7.0

本版新增本地离线英语跟读，形成“听原音 → 录音 → 查看词级反馈 → AB 对比 → 再读一次”的练习流程。

## 功能更新

- **随手开始跟读**：长按课本句子，或点击底栏麦克风选择当前页的一句话，打开跟读抽屉。进入跟读会停止旧点读与连读队列，原音和自录音试听使用同一播放器，避免声音重叠。
- **本地离线识别**：内置约 **70.04 MiB** 的量化英文 Sherpa-ONNX 模型，首次进入跟读才在独立 isolate 准备和加载；录音期间流式识别，运行时不下载模型、不上传语音。
- **实时录音声浪**：根据真实麦克风音量展示声浪与录音动效；支持点击停止、最长 15 秒保护，以及说话后静音 1.5 秒自动停止并评分。
- **逐词反馈与跟读匹配分**：将识别文本与课本原句进行动态规划对齐，显示绿／黄／红词级反馈、漏读和错词，提供 0–100 综合跟读匹配分及练习提示。点击红色词可以重听它所在的课本完整原句。
- **原音／自录音 AB 试听**：“听标准音”播放原有课本音频，“听我的录音”播放本次临时 WAV；评分后可以“再读一次”或“完成”，重复练习会清理上次录音。
- **动态授权与完整清理**：只在点击录音时申请麦克风权限，拒绝后可重试，永久拒绝时提供系统设置入口。后台和系统录音中断会取消本次录音；关闭抽屉停止试听、释放原生推理与麦克风、删除临时文件。
- **保留现有点读体验**：三种播放模式、暂停／继续、气泡音频、六档倍速、通知降音、阅读进度和应用内更新保持可用；修复自动翻页动画期间长按句子的入口，并确保退出跟读时播放器异常也不会阻止资源释放。

### 评分范围

当前 Sherpa 流式 Dart 接口提供识别文本、词元和时间戳，**不提供原生词级置信度**。本版颜色与分数依据文本匹配和完整度，不是专业声学发音评测，不能判断音素、重音、语调或口音，也不伪造模型概率。儿童声音、教材人名和环境噪声可能影响识别，请结合 AB 试听练习。

- 内置英文模型 73,440,167 字节（约 70.04 MiB），来源版本固定，模型文件已核对 SHA-256。
- Android API 36 x86_64 断网模拟器已验证权限拒绝／重试授权、真实麦克风录音、15 秒自动停止、0 分漏读词级反馈与原音／自录音 AB 试听。
